# Asaan Dukan - POS System 🛒

A simple Point of Sale (POS) system for small shops in Pakistan, built with FastAPI.

**Made by a Developer from Mardan**

### Features
- ✅ View all products (GET /products)
- ✅ Add new products (POST /products)
- ✅ Create customer bill (POST /bill)
- ✅ Auto stock management

### Tech Stack
- Python
- FastAPI
- Pydantic

### How to Run
pip install fastapi uvicorn
uvicorn main:app --reload
Then open: http://127.0.0.1:8000/docs
